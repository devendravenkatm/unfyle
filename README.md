# Unfyle

Unfyle is a Python-based document management project that I am building while learning Python and software development.

The goal is to eventually build a tool that can organize documents, extract information from them, and make their contents easier to search.

## Current Features

- Add documents using a file path
- Automatically detect file name and type
- Get file size
- Validate whether a file exists
- List added documents
- Search documents by name
- Case-insensitive document search
- Save document metadata to JSON
- Load saved documents when the application starts
- Basic error handling

## Technologies

- Python
- JSON
- pathlib

## Current Status

Early development.

I am building Unfyle incrementally while learning Python fundamentals, programming concepts, and software development practices.
